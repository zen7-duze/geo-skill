# 写能被 AI 引用的文章

挑一条 AI 回答里没有你的问题,写一篇**结构上让 AI 愿意引用**的文章。

**差异化不是"AI 写文章"** —— 满市场都是。是**写完先过一遍广告法词库和资质校验**:极限词、绝对化用语、未持证的功效宣称,发之前就拦下来。

## 能做什么

针对你缺席的那个问题,写一篇**结构上让 AI 愿意引用**的文章。

- 生成草稿(异步),文风可参照你已有的稿子
- **发布前先过广告法词库和资质校验**:极限词、绝对化用语、未持证的功效宣称,写完就拦
- 文章管理:列清单、看全文、看待审、审核通过 / 驳回(带原因)
- 免费段是提纲 + 首段 + 合规预检结论;**全文与配图收费**

差异化不是「AI 写文章」——满市场都是——是**发出去之前先替你把合规问题挑出来**。

## 前置

需要授权:`python scripts/geo_client.py login`。

## 怎么用

> 下面的命令**由 AI 助手执行,你不用敲** —— 直接用上面那些话问它就行。

```bash
python scripts/geo_client.py chat "针对「XXX 哪家好」这个问题写一篇能被 AI 引用的文章"
python scripts/geo_client.py chat "看看我的文章列表 / 这篇合规检查过了吗"
```

产稿是**异步**的,发起后如实报时,别原地等。

## 合规检查

- 合规检查报错时,**照原文告诉用户是哪一句触发了哪条规则**,并给出改法建议;不要含糊说「有点问题」。
- **不会代写资质、认证、获奖或效果承诺。** 默认一律不写。用户有真实资质要写进去,让他自己提供,并提醒他这些内容需要能拿出证明。
- 用户要求写「行业第一」「最好」「100% 有效」这类表述时,直接说明这在国内会触发广告法,给出合规替代说法。

## 免费与墙

- **免费**:提纲 + 首段成稿 + 合规预检结论
- **墙**:全文 + 配图 → 收费

到墙的那一刻要说清:做什么、花多少、余额还剩多少,然后停下等用户回话。

## 余额与付费(撞到 402 时看这里)

发文、投放这类动作是**收费**的,走账号的算力点钱包。

```bash
python scripts/geo_client.py wallet          # 看余额 —— 花钱的动作之前先看一眼
python scripts/geo_client.py topup 100       # 充值 100 元:返回怎么付
python scripts/geo_client.py topup 100 --tx 0x…   # 链上付完,带交易哈希来核销
```

**撞到 `402` 不是出错**,是「要付费」:响应里带着还需要多少、当前余额、以及两条充值路径。

- **让用户去网页充值**(微信扫码):把响应里 `web` 给的页面地址告诉他
- **你自己付**(agent 直付):按 `accepts` 里的网络、资产、收款地址、金额付款,
  拿到交易哈希后 `topup <金额> --tx <哈希>` 核销入账

三点说明:

- **金额和收款地址原样念,一个字都别改、别自己算。** 付错地址的钱找不回来。
- **余额不足时不要反复重试** —— 每次都会失败,而且会让用户以为是系统故障。停下来说清要充多少。
- **不要替用户决定充多少。** 报出这一单需要的数,让他决定。
