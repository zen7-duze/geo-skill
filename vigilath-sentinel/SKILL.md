# 品牌舆情哨兵

抓**真实社交媒体上真人发的帖子**,做情感判定与风险分级,带原帖链接和发布时间。

⚠️ 这和「拿口碑类问题去问 AI、看 AI 怎么回答」是**完全不同**的两件事。我们抓的是真人真发的内容。用户拿别家报告来比时,这一点值得直接点明。

## 能做什么

抓**真实社交媒体上真人发的帖子**,不是"拿口碑问题去问 AI"。

| 看什么 | 内容 |
|---|---|
| 今日概况 | 舆情 KPI、7 天趋势、风险分布、最新简报、高风险 Top |
| 负面明细 | 每条带**原帖链接和发布时间**,给不出链接的结论就不说 |
| 历史回溯 | 某段时间有哪些负面(可追溯很久) |
| 实时热榜 | 当前热点,找可蹭的话题 |
| 监测词 | 改关键词 / 别名 / 品牌名 |

免费段是今日前 5 条 + 热榜全量;历史、预警推送、配监测词收费。

## 你可以这样问

- 「今天有没有负面」「舆情怎么样」
- 「上个月有哪些负面」
- 「今天有什么热点可以蹭」
- 「把监测词加上 XX」

## 何时用

- 「今天有没有负面」「舆情怎么样」「有人在骂我们吗」「风险高不高」
- 「以前某段时间有哪些负面」(可追溯很久)
- 「今天有什么热点可以蹭」
- 「帮我把监测词/关键词改成 ⋯⋯」

**这是一条独立业务线** —— 不要顺势推销 AI 可见性相关的能力。买舆情和买 GEO 的常常是两个部门,触发语、数据源、决策人都不同。

## 前置

需要授权:`python scripts/geo_client.py login`。

## 怎么用

```bash
python scripts/geo_client.py chat "今天舆情怎么样?有没有负面?"
python scripts/geo_client.py chat "上个月有哪些负面"
python scripts/geo_client.py chat "今天有什么热点可以蹭"
python scripts/geo_client.py chat "把监测词加上 XXX"
```

## 展示纪律

- **情感分用百分比**表述;立场 / 意图 / 事实性这些判定必须用中文说法,不要念英文枚举值。
- 每条负面**给原帖链接和发布时间**。给不出链接的结论不要说。
- 展示的是**新鲜度窗口内**的内容(默认最近几天),不是全量库存 —— 用户问「一共多少条」时说明这个口径。
- 舆情任务出错时不要向用户渲染报错细节,如实说「这个账户的抓取暂时没有结果」即可。

## 免费与墙

- **免费**:今日前 5 条 + 热榜全量
- **墙**:历史回溯、预警推送、监测词配置 → 收费

配监测词是会真的触发抓取的动作,属于要停下来确认的一步。
