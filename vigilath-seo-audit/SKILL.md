# 传统 SEO 体检

给一个网址,12 类 SEO 检查逐项跑完,回一个独立的 0–100 分与等级。

**免登录、免费、不限次。**

## 能做什么

给一个网址,12 类传统 SEO 逐项检查:标题标签、描述、标题层级(H1/H2)、
图片替代文本、链接、可索引性等,回一个**独立的 0–100 分**。

免费档能看 3 类明细(标题标签 / 描述 / 标题层级),其余只报类目名。

**这个分和 GEO 分是两套口径,永远分开说** —— 一个站可能传统 SEO 85 分、
而 AI 友好度只有 C 级,这个反差本身就是最该告诉用户的事。

## 具体查哪些项

**SEO 12 项**,★ 是免注册可见明细的:

| | 类目 | 说人话 |
|---|---|---|
| ★ | 标题标签 | 每页标题写没写、有没有重复 |
| ★ | 描述标签 | 搜索结果里那段摘要 |
| ★ | 标题层级 | H1/H2 结构乱不乱 |
| | 可索引性 | 页面允不允许被收录 |
| | 网址 / 规范标签 / 跳转 | 网址结构与重定向是否规范 |
| | 站内链接 | 内部链接布局 |
| | 图片 SEO | 图片有没有替代文字 |
| | 富结果结构化数据 | 能不能出星级、价格这类富摘要 |
| | 页面速度信号 | 加载快不快 |
| | 移动端可用性 | 手机上好不好用 |
| | 抓取指令与站点地图 | 抓取规则配得对不对 |
| | 多地区定向 | 面向不同地区/语言的设置 |

分数是**全部项目都真跑出来的**,所以可信;免注册只是不给你看锁住那些项的**明细结论**。

```bash
python scripts/geo_client.py check https://example.com --seo-only
```

返回 `seo.score` / `seo.grade` / `seo.visible_categories` / `seo.locked_categories`,结构与网站体检一致。

## 两个分数不要混

**SEO 分和 GEO 分是两套独立口径,永远分开说。**

- 不要相加、不要平均、不要合成「综合分」
- 一个站完全可能 SEO 85 分而 AI 友好度 C 级 —— 这正是值得对用户点出来的事实:
  「传统搜索那套你做得不错,但 AI 那套是另一套规则,你还没做」
- 用户问「那我到底几分」时,如实给两个数字加一句口径,别为了好回答就揉成一个
