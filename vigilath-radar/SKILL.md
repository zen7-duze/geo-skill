# 提问词雷达

把用户的品牌/行业展开成**客户真的会对 AI 说的那些话**(不是搜索关键词,是完整提问),并标出哪些问题上他完全不存在。

## 能做什么

把品牌/行业展开成**客户真的会对 AI 说的那些话**,并标出你在哪些问题上不存在。

- 一次约 40 条候选,按四类场景分组:检索型 / 问答型 / 意图型 / 品牌型
- 每条标三态:**已命中**(测过、AI 提到你)、**未命中**(测过、没提到)、**未测**(压根没测过)
- 看得见缺口是免费的;把选中的问题变成**持续监测**要收费

三态**绝不能混说** —— 把「未测」讲成「未命中」,等于凭空给用户捏一个缺口。

## 你可以这样问

- 「客户会拿什么问题问 AI」
- 「我该盯哪些问题」
- 「哪些提问我完全没覆盖」

## 何时用

- 「客户会怎么问 AI」「用户会拿什么问题搜我这行」
- 「我该盯哪些问题」「哪些提问我没覆盖到」
- 「帮我找关键词 / 选词」

## 前置

需要授权:`python scripts/geo_client.py login`。

## 怎么用

```bash
python scripts/geo_client.py chat "帮我扩一批客户会问 AI 的问题,行业是 XXX"
python scripts/geo_client.py data coverage    # 累计被命中的问题数 / 种子词数
```

扩词按四类场景展开(检索型 / 问答型 / 意图型 / 品牌型),一次给约 40 条候选。

## 三态纪律

每条问题有三种状态,**必须分开说,永远不要合并**:

- **已命中** —— 测过,AI 回答里出现了这个品牌
- **未命中** —— 测过,AI 回答里没有这个品牌 ← 这才是缺口
- **未测** —— **根本没测过**

把「未测」说成「未命中」,等于凭空给用户捏造一个缺口。别人的产品把这两者混在一起,我们不能。

## 免费与墙

- **免费**:40 条候选词全预览 + 缺口标记,随便看
- **墙**:把选中的问题**落库变成持续跟踪**(进入监测跑批)是收费的

分界线对用户很好讲:**看得见缺口不要钱,让我们持续替你盯着才要钱。**

落库前必须停下来确认,说清这一步开始计费。用户只是想看看的话,预览完就停,别自作主张落库。
