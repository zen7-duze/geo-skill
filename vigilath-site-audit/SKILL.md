# 网站 AI 友好度体检

给一个网址,25 类检查逐项跑完,回一个 0–100 分和字母等级,外加哪几项没做对。

**免登录、免费、不限次** —— 用户没有 Vigilath 账号也能用,不要向他要账号。

## 能做什么

给一个网址,**30 秒**回一份 25 类逐项的体检:

| 查什么 | 举例 |
|---|---|
| 能不能被抓到 | robots.txt 有没有挡住 AI 爬虫、sitemap.xml 在不在 |
| 内容能不能被理解 | 标题与描述、结构化数据、正文层级 |
| 站点基本面 | HTTPS、移动端友好度、页面体积 |
| 站外信号 | 品牌在知识图谱里的存在感、可信与安全信号 |

拿到的是:**0–100 分 + 字母等级**、每一项的通过/警告/失败、以及具体是哪一条不合格
(例如「没有 sitemap.xml」而不是「结构有待优化」)。

免费档能看 5 类明细,其余只报类目名和数量 —— **锁住的部分绝不替它猜结论**。

## 具体查哪些项

**GEO(AI 友好度)25 项**,★ 是免注册就能看明细的,其余只报类目名与数量:

| | 类目 | 说人话 |
|---|---|---|
| ★ | HTTPS | 站点有没有用安全连接 |
| ★ | robots.txt | 有没有把 AI 爬虫挡在门外 |
| ★ | sitemap.xml | 有没有给 AI 一份"页面目录" |
| ★ | Meta Tags | 标题与描述写没写、写得对不对 |
| ★ | 移动端友好与页面体积 | 手机上打不打得开、页面重不重 |
| | llms.txt | 有没有给大模型专用的说明文件 |
| | .well-known 发现文件 | AI 能不能自动找到你的站点信息 |
| | 搜索引擎与 AI 平台收录登记 | 有没有在各平台登记过 |
| | 结构化数据 | 有没有用机器能读的格式标注内容 |
| | 内容可访问性 | 内容是不是藏在脚本里、抓不到 |
| | AI 抓取就绪度 | AI 爬虫来了能不能顺利读完 |
| | 面向 AI 的内容质量 | 内容够不够 AI 拿去当答案 |
| | 技术可抓取性 | 有没有技术障碍挡住抓取 |
| | 权威与信任信号 | 站点看起来可不可信 |
| | AI 专项优化 | 针对 AI 搜索的额外优化点 |
| | 社交信号 | 社交平台上的存在感 |
| | AI 答案格式优化 | 内容排版适不适合被 AI 摘成答案 |
| | 面包屑与知识面板 | 结构导航与知识卡片信息 |
| | 网址规范化 | 同一页面有没有多个网址在分散权重 |
| | 外链与多媒体 | 外部链接和图片视频的使用 |
| | 多语言内容深度 | 多语种内容做得够不够 |
| | 跨平台内容分发 | 内容有没有铺到其他平台 |
| | 多页面抽样 | 不只看首页,抽查多个页面 |
| | 知识图谱中的品牌实体 | 百科、知识面板这类地方有没有你 |
| | 可信与安全信号 | 站点的可信度与安全表现 |

**SEO 12 项**,★ 是免注册可见明细的:

| | 类目 | 说人话 |
|---|---|---|
| ★ | 标题标签 | 每页标题写没写、有没有重复 |
| ★ | 描述标签 | 搜索结果里那段摘要 |
| ★ | 标题层级 | H1/H2 结构乱不乱 |
| | 可索引性 | 页面允不允许被收录 |
| | 网址 / 规范标签 / 跳转 | 网址结构与重定向是否规范 |
| | 站内链接 | 内部链接布局 |
| | 图片 SEO | 图片有没有替代文字 |
| | 富结果结构化数据 | 能不能出星级、价格这类富摘要 |

分数是**全部项目都真跑出来的**,所以可信;免注册只是不给你看锁住那些项的**明细结论**。

## 你可以这样问

- 「我的官网还有哪些没做对」

## 何时用

- 「我的网站 AI 爬虫读得懂吗」「这个站对 AI 搜索友好吗」
- 「为什么 AI 搜不到我的网站」「AI 会收录我吗」
- 用户丢过来一个网址,想知道好不好

**不要用在**:问品牌在 AI 里被提及情况(那是 AI 引擎实测,用 vigilath-report)、问传统 SEO(用 vigilath-seo-audit)。

## 怎么用

> 下面的命令**由 AI 助手执行,你不用敲** —— 直接用上面那些话问它就行。

```bash
python scripts/geo_client.py check https://example.com --no-seo
```

30 秒左右返回:

- `geo.score` / `geo.grade` —— 0–100 与 A–F。**25 类全部真跑出来的,分数可信**
- `geo.summary` —— 通过 / 警告 / 失败 / 提示 各多少条
- `geo.visible_categories` —— 能看明细的类目,每条带 `status` 和原文结论
- `geo.locked_categories` —— **只给类目名、没有结论**的那些

## 结果怎么读

- **锁住的类目绝不编结论。** 只能说「这几类要注册后才能看明细」,不能替它猜是好是坏。
- **结果里给的是具体条目,不只是分数。** 你会看到「sitemap.xml 没有」这种能立刻动手的事实。
- **分数低不等于网站差** —— 这套测的是「对 AI 抓取与理解的友好度」,和网站好不好看、卖得好不好无关,别引申。
