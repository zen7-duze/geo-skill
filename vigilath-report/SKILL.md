# AI 体检报告(一键全面诊断)

拿用户的品牌**真的去问 AI 引擎**,把原话和采集时间贴回来,合成五维评分与十一章报告。

八项子检测:官网体检 / 答案引擎优化 / 爬虫可达性 / 站外权威 / AI 可见性实测 / 品牌实体认知 / 竞品情报 / 舆情。

## 能做什么

一份能直接发给老板的诊断报告,**十一章 + 可导 PDF**,整单 8–20 分钟。

八项子检测:官网体检 · 答案引擎优化 · 爬虫可达性 · 站外权威 ·
AI 可见性实测 · 品牌实体认知 · 竞品情报 · 舆情。

报告里有:五维评分(带**计算公式和输入项**)、逐条问题的命中情况与位次、
竞品对比、用户画像与场景意图、优先级动作与路线图。

**每个数字都能下钻到引擎原话和采集时间** —— 用户质疑时,把原话给他。

每个账号**终身赠 1 次**完整报告;之后按订阅档给月配额。

## 前置

需要授权:`python scripts/geo_client.py login`(终端出配对码,用户到浏览器批准)。

**不需要先建主题、不需要有官网** —— 用户报个品牌名就能跑;没官网时站点侧四项自动跳过,AI 侧四项照常。别因为缺资料就拒绝或催建站。

## 怎么用

发起(自然语言交给平台 agent 决定参数):

```bash
python scripts/geo_client.py chat "帮我跑一次全面诊断,品牌叫 XXX,行业词是 XXX"
```

查进度或取结果:

```bash
python scripts/geo_client.py data diagnosis
```

## 时间纪律(最容易做错的地方)

- **整单 8–20 分钟。** 发起后**如实告诉用户要等多久,让他先去忙**,回来问「报告好了吗」。
- **绝不在同一轮里反复查进度。** 发起 → 报时 → 停。用户下次问起时再 `data diagnosis`。
- 不要说「马上好」「稍等一下」这种会让用户干等的话。

## 数据纪律

- **每个数字都能下钻到引擎原话和采集时间** —— 这是这份报告和同类产品的根本区别,用户质疑时就把原话给他。
- 某个引擎没跑成,如实说「本次实测 N 个引擎」,**不要用估算值补格子**。
- 报告里标了「未测」的问题,就是没测过,**不等于没命中**,三态不能混说。
