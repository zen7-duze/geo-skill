# Vigilath GEO 优化

把本宿主 agent 链接到 Vigilath——检测·审计·优化·监控品牌在 AI 搜索引擎中的可见性。

两层能力,门槛完全不同:

- **免登录层**:任何网站的 GEO + SEO 体检(`check`),免费、不限次、不需要任何凭证。**先用这层**——
  用户还没有 Vigilath 账号时也能立刻拿到真实分数。
- **授权层**:绑定某账号的 GEO agent(一只"小龙虾"),看该账号的真实投放数据、跑一键全面诊断、
  查舆情、产稿。需要装 skill 时做过设备码授权。

## 能做什么

下面每一项都是真做得到的,不是宣传语。**免登录**那几项装完就能用;其余需要跑一次 `login` 授权。

### 检测(免登录、免费)

| 能力 | 给什么 | 得到什么 |
|---|---|---|
| 网站 AI 可读性体检 | 一个网址 | 25 类逐项评分 + 0–100 分与等级,哪几项没做对 |
| 传统 SEO 体检 | 一个网址 | 12 类 SEO 评分 + 独立分数(与 GEO 分**分开算**) |
| AI 提及快测 | 品牌 + 行业词 | 3 个引擎 × 3 条品类问题的**引擎原话**,AI 推荐了谁、有没有你 |
| 行业榜 | 行业名 | 该行业 AI 里谁是 TOP1、集中度、走势(仅已建库行业) |
| AEO 可见性审计 | 一个网址 | 页面内容对「AI 生成答案」的适配程度、逐页评分、最弱信号与优先改进项 |
| AI 爬虫测试 | 一个网址 | 主流 AI 爬虫能不能真抓到这个页面、Common Crawl 收录情况 |

上面四项**零引擎成本、不限次**。下面四项也免登录,但每次都是**真实付费调用**,

## 何时用

用户(或上游任务)涉及以下任一,就调用本 skill:

**网站体检(免登录,优先考虑这条)**

- 「**测一下**这个网站」「这个站 **GEO/SEO 怎么样**」「帮我**体检**一下官网」
- 「我的网站对 AI 友好吗」「为什么 AI 抓不到我的站」
- 用户给了一个网址、想知道好不好——**别问他要账号,直接 `check`**

**GEO 可见性**

- 「我的品牌/产品在 AI 搜索里**被搜到几个**问题?」「AI 可见性怎么样?」
- 「帮我**诊断** GEO/AEO 现状」「为什么 AI 不引用我?」
- 「**竞品**在 AI 引擎里的表现对比」
- 「今天/累计**投放效果**、命中率」「**日报/周报/月报**怎么样」「**达标**了吗」
- 「怎么**优化/产稿**提升被 AI 引用率」

**舆情监控**(同一个 token,同一套接口)

- 「今天**舆情**怎么样 / 有没有**负面** / 风险高不高」
- 「**以前/某段时间**有哪些负面」(可追溯很久)
- 「今天有什么**热点/热榜**可以蹭」
- 「帮我把**监测词/关键词**改成 ⋯⋯」

不涉及以上两类的普通问题,不要调用。

## 怎么用

脚本在 `scripts/geo_client.py`,纯标准库、零依赖。

- **网站体检**(免登录、免费、不限次;整站 25 类 GEO + 12 类 SEO 全跑,十几秒到一分钟):
  ```bash
  python scripts/geo_client.py check https://example.com
  python scripts/geo_client.py check https://example.com --no-seo   # 只要 GEO
  ```
  返回 `geo` / `seo` 两半,各有 0–100 分与等级。**分数是全量跑出来的、真实**;
  但 `visible_categories` 只有免费档能看的那几类明细,其余在 `locked_categories` 里
  **只给类目名、不给结论**,也没有修复建议。念分数和已见明细即可,
  **不要对锁住的类目编造结论**;想要完整明细就照 `note` 引导用户注册后 `login`。

- **AI 提及快测**(免登录,每台设备 2 次 / 30 天):拿品牌**真的去问 AI**,把原话贴回来。
  ```bash
  python scripts/geo_client.py mention 你的品牌名 商用清洁机器人
  python scripts/geo_client.py mention-status <task_id>    # 等超时了再查
  ```
  问的是**品类问题**(「XX 推荐」「XX 哪个品牌好」),不是「你家怎么样」——
  品牌自查题的答案里必然出现品牌名,看不出有没有被推荐。约 1–3 分钟。
  **把 `answer_excerpt` 里的引擎原话念给用户**,那才是最有价值的产出;
  `mentioned_in`/`answered` 是计数,**不要换算成百分比**,3 条问题的样本量不支持算率。

- **高级检测**(免登录;前两个零成本不限次,后四个有额度):
  ```bash
  python scripts/geo_client.py advanced aeo https://example.com          # AEO 可见性审计
  python scripts/geo_client.py advanced crawl-test https://example.com   # AI 爬虫测试
  python scripts/geo_client.py advanced authority https://example.com    # 权威信号(有额度)
  python scripts/geo_client.py advanced citation https://example.com     # AI 引用检测(有额度)
  python scripts/geo_client.py advanced entity 某某品牌 brand             # 实体审计,不用网址(有额度)
  python scripts/geo_client.py advanced compare https://a.com https://b.com   # 多站对比(有额度)
  ```
  返回里的 `note` 会写明这一项是零成本还是有额度,`quota` 给出还剩几次。
  **额度用完回 429,如实转达并停下**,别反复重试 —— 每次重试都在花钱。

- **行业榜**(同样免登录、免费):看某行业在 AI 搜索里谁是 TOP1、集中度多高。
  ```bash
  python scripts/geo_client.py industry                    # 已建库的行业清单
  python scripts/geo_client.py industry 商用清洁机器人      # 该行业详情
  ```
  **只覆盖已建库的行业**。用户的行业不在清单里就如实说,
  **绝不拿别的行业的数字替代**,也不要把行业数据说成用户自己品牌的表现。

- **对话式**(让 GEO agent 自己跑工具、给结论 + 结构化卡片):
  ```bash
  python scripts/geo_client.py chat "今天投放效果怎么样?累计被搜到几个问题?"
  ```
  输出 = 一段自然语言回答 + 一段「结构化卡片」JSON(命中数字、竞品等)。**把卡片里的数字念给用户**,别只复述自然语言。

- **只取数**(不走大模型,更快、更省;只要数字时用):

  | 命令 | 拿到什么 |
  |---|---|
  | `data overview` | 报告中心最新数据:日/周/月各最新一期的六项指标 + 环比 + 达标 |
  | `data period` | 某一期详情:六项指标 + 环比 + 分平台整体露出率 + 该期 AI 总结正文 |
  | `data periods` | 最近若干期的六项指标(新→旧),看走势 |
  | `data coverage` | 累计被命中的问题数 / 种子词数(问题级去重) |
  | `data publish` | 发布进度 + 已发布文章列表 |
  | `data diagnosis` | 一键全面诊断的进度或结果摘要 |
  | `data run` | 最近一次跑批的执行状态(跑完没 / 多少条 / 哪个平台报错) |

  ```bash
  python scripts/geo_client.py data overview
  ```

  旧名 `today` / `growth` / `batch` / `report` 仍可用(分别等价于 `overview` / `overview` / `run` / `diagnosis`),新接入一律用上表的新名。

- **看权限**(当前 token 能做什么,决定要不要提"产稿/发布"):
  ```bash
  python scripts/geo_client.py capabilities
  ```

## 鉴权

`check` **不需要凭证**,没装 token 也能跑。其余命令都要:

脚本从环境变量读凭证,**绝不硬编码、绝不打印 token**:

- `VIGILATH_AGENT_TOKEN`(必填)—— 1 年期账号 token,由 Vigilath 领号发放。
- `VIGILATH_BASE`(选填)—— 默认 `https://vigilath.cn/api/agent/v1`;一行安装会按你的站点域名自动写好,通常不用管。

凭证失效时可重新授权(终端出配对码、用户到浏览器批准,不用重装 skill):

```bash
python scripts/geo_client.py login
```

## 数字口径(必须遵守,说错数比不说更糟)

- **只念接口返回的数字**,绝不自己换算、绝不把不同命令的数字相加或相除。返回的百分比已经是最终值(0–100 且已四舍五入),**不要再乘 100**。
- 六项指标的名字**照抄返回里的 `metric_labels`**:整体露出率、TOP1露出率、TOP3露出率、内容中正率、文章引用率、品牌声量度。**不要自创**「命中率」「曝光率」「覆盖率」来指代它们。
- **以「已收口」的期次为准**:日报最新一期是**昨天**,今天的还在跑。用户问「今天怎么样」时先给已收口的数字,再补一句今天的进行中数据并**标明未收口、仅供参考**,绝不拿它下结论。
- **「达标了吗」一律看周报**,不要用日报数字回答。
- `coverage`(问题有没有被搜到过,按问题去重)与整体露出率(每条应答里有没有提到本品,按应答)**是两个口径**,不可混用、不可互相换算、不可在同一句里当同一指标解释。
- `data diagnosis` 是「一键全面诊断报告」,**不是**报告中心的日/周/月报,别混为一谈。

## 余额与付费(撞到 402 时看这里)

发文、投放这类动作是**收费**的,走账号的算力点钱包。

```bash
python scripts/geo_client.py wallet          # 看余额 —— 花钱的动作之前先看一眼
python scripts/geo_client.py topup 100       # 充值 100 元:返回怎么付
python scripts/geo_client.py topup 100 --tx 0x…   # 链上付完,带交易哈希来核销
```

**撞到 `402` 不是出错**,是「要付费」:响应里带着还需要多少、当前余额、以及两条充值路径。

- **让用户去网页充值**(微信扫码):把响应里 `web` 给的页面地址告诉他
- **你自己付**(agent 直付):按 `accepts` 里的网络、资产、收款地址、金额付款,
  拿到交易哈希后 `topup <金额> --tx <哈希>` 核销入账

三条纪律:

- **金额和收款地址原样念,一个字都别改、别自己算。** 付错地址的钱找不回来。
- **余额不足时不要反复重试** —— 每次都会失败,而且会让用户以为是系统故障。停下来说清要充多少。
- **不要替用户决定充多少。** 报出这一单需要的数,让他决定。

## 边界(照实告诉用户)

- `check` 测的是**站点自身对 AI 的友好度**(可抓取性、结构化、元信息、权威信号等静态信号),
  **不等于** AI 引擎实际怎么说这个品牌。用户问「AI 到底提不提我 / 引不引用我」时,
  别拿体检分回答——那要「一键全面诊断」(走 `chat`,需授权,整单 8–20 分钟)。
- 引擎选择、查询调度、频率由 Vigilath 平台固定,**你和用户都不能指定**,只看结果。
- **真实对外发布**不在本 skill 能力内(受平台内部护栏控制);本 skill 只做查询 / 诊断 / 归因 / 优化建议。
- **一键全面诊断是重任务,整单 8–20 分钟**:发起后如实告诉用户要等多久、让他稍后回来看,**不要在同一轮里反复查进度**,也不要谎称"马上好"。
- 遇到返回里有 `gated: true`:这是**需开通的付费能力**,如实转达并请用户联系 Vigilath,**绝不谎称已设置成功或已落库**;不要重试、不要换个说法再试。
- 一个 token = 一个账号,只能看该账号自己的数据。
- 出现 `401` 报错 = token 无效/过期。让用户跑 `python scripts/geo_client.py login` 重新授权;
  仍不行再联系 Vigilath。**别重试刷接口**。
